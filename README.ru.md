# Codex Touch Bar

**Остаток лимитов Codex — прямо над клавиатурой.**

Небольшой помощник для MacBook Pro с Touch Bar. Показывает оставшиеся проценты
пятичасового и недельного лимитов, когда открыт ChatGPT или Codex.

![Полоски прогресса на Touch Bar](assets/touchbar-preview.png)

*На иллюстрации условные значения: 82% и 30% остатка.*

## Что умеет

- Компактный индикатор двух лимитов в Control Strip; нажатие открывает широкие полоски.
- Цвет по остатку: зелёный, жёлтый, красный.
- Три оформления — полоски, компактные проценты и кольца.
- Выбор через **CX → Appearance / Оформление** в строке меню; настройка сохраняется.
- Время до сброса — в меню строки; обновление можно запустить вручную.
- Даты сброса в меню, обновление каждые 30 секунд, автозапуск после входа в macOS.
- При закрытии ChatGPT/Codex индикатор скрывается. При ошибке появляются прочерки.

## Установка

Нужны MacBook Pro с физическим Touch Bar, macOS 13+, установленный ChatGPT/Codex
с CLI и существующий вход в аккаунт ChatGPT. Архив универсальный: Apple silicon
и Intel. Получение лимитов и автозапуск проверены на M1 и macOS 26.5;
компактный виджет проверен на панели. Нажатие для открытия подробного вида в
v1.2.1 требует повторной проверки на устройстве. На Intel пока не проверено.
Это **экспериментальная версия**. Интерфейс поддерживает русский, английский
и язык macOS.

1. В разделе **Releases** скачайте `CodexTouchBar-v1.2.1-universal.zip`.
2. Распакуйте архив.
3. Запустите `Install.command`. Приложение установится в `~/Applications`,
   автозапуск — в `~/Library/LaunchAgents`.
4. Откройте ChatGPT или Codex. В строке меню появится **CX**, на Touch Bar —
   индикатор. При необходимости разверните Control Strip справа.

Приложение подписано локальной подписью, но не нотарифицировано Apple.
macOS может попросить отдельно разрешить открытие. Пароль администратора
не нужен. Можно запускать приложение вручную без установки автозапуска.

## Данные и ограничения

Используется официальный метод `account/rateLimits/read` установленного Codex CLI.
Остаток вычисляется как `100 − использованный процент`. Авторизация остаётся
в Codex; помощник не копирует токены, не собирает аналитику и не отправляет
запросы модели. Для обновления лимитов Codex обращается к сети.

Виджет Touch Bar использует частные интерфейсы macOS. После обновления системы
они могут измениться; в таком случае остаётся индикатор строки меню.
Это независимый проект, не официальный продукт OpenAI или Apple.

Если видны прочерки, проверьте вход через ChatGPT в Codex CLI и выберите
**CX → Refresh now / Обновить сейчас**. Один API-ключ не предоставляет лимиты подписки ChatGPT.
Для диагностики рядом с установленным приложением создаётся
`CodexTouchBar-status.json`, без токенов и полного ответа сервера.

## Сборка и удаление

С Apple Command Line Tools выполните `bash build.sh`. Архив и контрольная сумма
появятся в `dist/`. Сторонние библиотеки не нужны.

Если macOS пересобрала Control Strip, помощник повторно включает виджет при
следующей проверке через 30 секунд.

`Uninstall.command` отключает помощник и удаляет автозапуск. Затем можно переместить
приложение из `~/Applications` в Корзину. Аккаунт, чаты и настройки Codex сохраняются.
